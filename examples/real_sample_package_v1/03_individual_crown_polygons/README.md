# Individual tree crown examples

Each example contains a 512 × 512 RGB image, a coloured contour preview, a TIFF instance mask and a crown-area CSV. The instance mask uses 0 for background and positive integer IDs for individual crowns. The CSV links each ID to its area in square pixels.

These TIFF masks and area tables are demonstration formats. The full release stores crown polygons, bounding boxes and areas in COCO JSON files. See the main README for the COCO fields and published source-scene splits.
