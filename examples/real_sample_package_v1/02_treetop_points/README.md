# Treetop-point examples

Each example contains a 1024 × 1024 overlay preview and equivalent CSV/JSON point coordinates. Coordinates use a top-left pixel origin, with x increasing to the right and y increasing downwards. Points were independently drawn by hand; marker size does not encode crown size.

These CSV/JSON files are a demonstration format; the full release stores treetop markers in SVG canvas coordinates. The 2 km × 2 km extent in the manuscript refers to full source scenes. A per-example geographic transform and ground footprint are not supplied here.
