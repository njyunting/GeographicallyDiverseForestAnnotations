# Forest canopy mask examples

Each example contains a 1024 × 1024 annotation overlay, aligned binary PNG/TIFF masks and a CSV recording canopy/background pixel counts and canopy coverage. The four examples span low, moderate and high canopy coverage.

These binary masks are a demonstration format; the full release stores canopy masks as RGB PNG/JPEG images. The 2 km × 2 km extent in the manuscript refers to full source scenes. A per-example geographic transform and ground footprint are not supplied here.
