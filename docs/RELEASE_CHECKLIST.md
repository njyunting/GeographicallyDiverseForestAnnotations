# Public Release Checklist

The repository must remain private and GitHub Pages must remain disabled until every box below is checked by the repository owner.

## Manuscript and identity

- [ ] Manuscript submitted to the target journal.
- [ ] Final dataset title confirmed across manuscript, repository and data deposit.
- [ ] Author order, affiliations and contact details verified.
- [ ] Paper DOI or stable manuscript identifier available.

## Data deposit

- [ ] Deposited release URL and version confirmed.
- [ ] File inventory, split metadata and checksums generated from the deposited release.
- [ ] Counts in the paper, README, landing page and deposit agree.
- [ ] Download and citation links tested from a logged-out browser.

## Rights and licensing

- [ ] Source-imagery provenance recorded for every displayed example.
- [ ] Redistribution permission confirmed for every public image.
- [ ] Google Earth or otherwise restricted imagery removed or replaced when permission is unavailable.
- [ ] Annotation-data licence selected.
- [ ] Code licence selected.
- [ ] Source-imagery terms documented separately from annotation and code licences.

## Technical and editorial checks

- [ ] README statements checked against the final manuscript.
- [ ] Website tested at desktop, tablet and mobile widths.
- [ ] Alt text and colour-independent labels reviewed.
- [ ] No placeholder DOI, contact, institution or release date remains.
- [ ] No disabled release control is accidentally linked to a private or incomplete archive.

## Publication approval

- [ ] Repository owner explicitly approves changing visibility from Private to Public.
- [ ] Repository owner explicitly approves any GitHub Pages or other deployment.
